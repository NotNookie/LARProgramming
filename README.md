# LARProgramming

Marketing landing site for **Larprogramming** — a web development studio building
fast, modern, custom websites for small businesses and brands.

Built with **Vite + React + Tailwind CSS**.



## Pages

- **Home** — hero, launch offer, and "What We Do" overview
- **Services** — what we build, the process, and the stack
- **Start a Project** — a friendly intake form that opens Facebook Messenger with
  the details pre-filled

## Getting started

```bash
npm install      # install dependencies
npm run dev      # start the dev server (http://localhost:5173)
npm run build    # production build -> dist/
npm run preview  # preview the production build locally
```

## Configuration

Edit `src/config.js` to update the Facebook page and Messenger links used across
the site.

## Tech stack

React - Vite - Tailwind CSS - React Router
